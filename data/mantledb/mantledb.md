## Overview

MantleDB is an anonymous JSON storage service for scripts and tiny applications. It requires no signup and uses a Master AID for updates and a Read-Only RID for public fetching.

## Features

- Anonymous JSON storage with no signup required
- Master AID for updates, Read-Only RID for public fetching
- Free tier includes 1 bucket with a 1 MB limit
- 72-hour inactivity scavenger policy

## Pricing

Free tier includes 1 bucket (1 MB limit).
