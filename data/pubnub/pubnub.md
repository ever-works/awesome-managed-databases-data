## Overview

PubNub is a real-time communication platform providing APIs for chat, push notifications, and real-time data streaming for web and mobile applications.

## Features

- Push notifications: up to 1 million messages/month free
- 100 active daily devices free
- Real-time data streaming
- Chat APIs
- Presence detection

## Pricing

Free tier includes up to 1 million messages/month and 100 active daily devices. Paid plans for higher volumes.
