## Overview

Activepieces is an open-source backend automation platform for building integration flows between applications.

## Features

- Connect multiple apps and services together
- Trigger-based automation (e.g., send Slack message when an event fires)
- Free tier includes up to 5,000 tasks per month
- Self-hosting available with open-source version
- MIT licensed

## Pricing

Free plan includes up to 5,000 tasks per month. Paid plans available for higher task volumes. Open-source self-hosted version available under MIT license.
