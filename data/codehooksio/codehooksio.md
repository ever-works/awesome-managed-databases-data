## Overview

codehooks.io is an easy-to-use JavaScript serverless API/backend and NoSQL database service.

## Features

- Serverless functions
- MongoDB-ish queries
- Key/value lookups
- Job system
- Realtime messages
- Worker queues
- CLI
- Web-based data manager
