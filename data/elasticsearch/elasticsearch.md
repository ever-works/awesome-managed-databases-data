## Overview

Elasticsearch is a distributed, RESTful search and analytics engine built on Apache Lucene. It is designed for horizontal scalability, reliability, and easy operational management.

## Features

- Distributed, RESTful search and analytics engine
- Full-text search, structured search, and analytics
- Horizontal scalability and high availability
- Near real-time search and indexing
- RESTful HTTP API

## Pricing

Open source under the Apache-2.0 license. Managed cloud options available via Elastic Cloud.
