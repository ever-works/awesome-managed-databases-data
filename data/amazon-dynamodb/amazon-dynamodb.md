## Overview

Amazon DynamoDB is a fully managed NoSQL database service provided by Amazon Web Services. It offers a free tier with 25GB of storage as part of AWS's always-free offerings.

## Features

- Fully managed NoSQL database
- 25GB storage on free tier
- Part of Amazon Web Services

## Pricing

Freemium model. Free tier includes 25GB of storage. Paid tiers available beyond free tier limits.

## Deployment

Cloud (Amazon Web Services)
