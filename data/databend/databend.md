## Overview

Databend is an open-source, elastic cloud data warehouse built for high-performance analytics.

## Features

- Open-source, elastic cloud data warehouse
- High-performance analytics with compute-storage separation
- Seamless integration with popular data tools
- Cloud-native and elastic scaling
- SQL-compatible analytics

## Pricing

Open source under the Apache-2.0 license. Managed cloud options available via Databend Cloud.
