## Overview

Baserow is an open-source no-code database and app builder that can be self-hosted or used on cloud.

## Features

- Open-source platform for building databases, internal apps, and automated workflows
- No-code database and app builder
- Spreadsheet-like interface
- Available on cloud or self-hosted
- API and integrations available

## Pricing

Open source under the MIT license. Hosted cloud options available via Baserow Cloud.
