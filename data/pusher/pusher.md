## Overview

Pusher is a hosted service for real-time messaging and push notifications, providing APIs for iOS, Android, and web applications.

## Features

- Unlimited free push notifications for 2000 monthly active users
- Single API for iOS and Android
- Channels for message routing
- Presence detection
- Webhooks

## Pricing

Sandbox plan is free with unlimited push notifications for 2000 monthly active users. Paid plans for higher user counts.
