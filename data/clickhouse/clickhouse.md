## Overview

ClickHouse is an open-source column-oriented database management system for online analytical processing (OLAP) workloads.

## Features

- Distributed SQL database combining OLTP and OLAP capabilities
- Horizontal scalability and high availability
- Real-time analytics on columnar, time-indexed data
- Sub-second query response times at scale
- SQL extensions for analytics

## Pricing

Open source under the Apache-2.0 license. Managed cloud options available via ClickHouse Cloud.
