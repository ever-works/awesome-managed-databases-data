## Overview

VictoriaMetrics is a fast, cost-effective and scalable time series database and monitoring solution.

## Features

- High-performance time series database for metrics and logs
- Compatible with Prometheus (remote write/read, PromQL)
- Handles billions of metrics with lower resource usage
- Designed for monitoring and observability workloads
- Single-node and cluster versions available

## Pricing

Open source under the Apache-2.0 license. Managed cloud options available via VictoriaMetrics Cloud.
