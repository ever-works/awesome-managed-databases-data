## Overview

8base is a full-stack low-code development platform built for JavaScript developers built on top of MySQL and GraphQL and serverless backend-as-a-service.

## Features

- UI app builder for rapid web application development
- Built on MySQL and GraphQL
- Serverless backend-as-a-service
- Scalable architecture

## Pricing

The Free tier includes:
- Rows: 2,500
- Storage: 500
- Serverless computing: 1Gb/h
- Client app users: 5

Paid plans available for scale.
