## Overview

CrateDB is a distributed open-source SQL database designed for real-time analytics.

## Features

- Distributed architecture
- SQL interface
- Real-time analytics
- Open source
- One cluster per organization on free tier
- No payment method required

## Pricing

Free Tier CRFREE: One node with 2 CPUs, 2 GiB of memory, 8 GiB of storage.
