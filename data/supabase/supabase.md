## Overview

Supabase is an open source Firebase alternative built on PostgreSQL. It is a combination of open source tools including Postgres, Realtime (Elixir server for database change listening via websockets), PostgREST (RESTful API from Postgres), GoTrue (JWT-based authentication API), Storage (S3-compatible file storage), pg_graphql (GraphQL API extension), postgres-meta (REST API for managing Postgres), and Envoy (edge and service proxy).

## Features

- Hosted Postgres Database
- Authentication and Authorization (GoTrue)
- Auto-generated REST API (PostgREST)
- Auto-generated GraphQL API (pg_graphql)
- Realtime subscriptions over websockets
- Database Functions
- Edge Functions
- File Storage (S3-compatible)
- AI + Vector/Embeddings Toolkit
- Dashboard
- Client libraries for JavaScript/TypeScript, Flutter, Swift, Python, C#, Go, Java, Kotlin, Ruby, Rust, and Godot

## Deployment

Supabase is a hosted platform that can be used without installation. It can also be self-hosted and developed locally.
