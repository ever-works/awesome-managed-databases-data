## Overview

Apache IoTDB is a time-series database built for industrial IoT workloads, managing high-throughput time-series data.

## Features

- Time-series database built for industrial IoT workloads
- High-throughput read/write
- Edge-cloud sync
- Ultra-high compression
- Integrations with Hadoop, Spark, Flink, and Grafana
