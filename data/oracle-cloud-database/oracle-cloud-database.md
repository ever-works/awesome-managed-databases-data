## Overview

Oracle Cloud offers managed database services with a free tier that includes 2 databases with 20GB of storage each. It is part of Oracle Cloud's always-free offerings for developers.

## Features

- Managed database service
- 2 databases on free tier
- 20GB storage per database on free tier
- Part of Oracle Cloud

## Pricing

Freemium model. Free tier includes 2 databases with 20GB storage each. Paid tiers available beyond free tier limits.

## Deployment

Cloud (Oracle Cloud)
