## Overview

Azure Cosmos DB is a fully managed NoSQL database service provided by Microsoft Azure. It offers a free tier with 25GB of storage and 1000 RUs of provisioned throughput as part of Azure's free tier offerings.

## Features

- Fully managed NoSQL database
- 25GB storage on free tier
- 1000 RUs of provisioned throughput on free tier
- Part of Microsoft Azure

## Pricing

Freemium model. Free tier includes 25GB storage and 1000 RUs of provisioned throughput. Paid tiers available beyond free tier limits.

## Deployment

Cloud (Microsoft Azure)
