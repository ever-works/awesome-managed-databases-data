## Overview

Layerbase provides a free-tier multi-engine database service including PostgreSQL as one of 7 supported database engines.

## Core Specifications

| Specification | Value |
|---|---|
| Storage | 5 GB |
| CPU | 0.5 |
| RAM | 0.5 GB |
| Backups | 1 manual backup slot |

## Limits

| Limit | Value |
|---|---|
| Network | N/A |
| Other Limits | 2 databases total |
| Pause Policy | Sleeps after 60 min idle, wakes automatically on connect in ~1-5 s. Archived after 14 days asleep; restorable from dashboard. |
