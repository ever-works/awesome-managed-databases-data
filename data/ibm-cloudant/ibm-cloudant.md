## Overview

IBM Cloudant is a fully managed NoSQL database service provided by IBM Cloud. It is based on Apache CouchDB and offers a free tier with 1GB of data storage.

## Features

- Fully managed NoSQL database
- Based on Apache CouchDB
- 1GB data storage on free tier
- Part of IBM Cloud

## Pricing

Freemium model. Free tier includes 1GB of data storage. Paid tiers available beyond free tier limits.

## Deployment

Cloud (IBM Cloud)
