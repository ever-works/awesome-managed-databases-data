## Overview

Neo4j is a native graph database platform built for storing and querying connected data using the Cypher query language.

## Features

- Graph database with sparse matrix representation and linear algebra
- Ultra-low latency Cypher queries
- Native multi-tenancy
- Built-in GraphRAG support for AI applications
- ACID-compliant transactions

## Pricing

Open source under the SSPL-1.0 license. Managed cloud options available via Neo4j Aura.
