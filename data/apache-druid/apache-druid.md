## Overview

Apache Druid is a high-performance, column-oriented, distributed data store designed for sub-second OLAP queries on streaming and batch data.

## Features

- Real-time analytics database for sub-second OLAP queries
- Columnar, time-indexed analytics database
- Handles billions to trillions of rows
- Millisecond query response times
- Built for streaming and batch data at scale
