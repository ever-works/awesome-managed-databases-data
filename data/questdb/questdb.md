## Overview

QuestDB is an open-source time-series database designed for high ingestion throughput and fast SQL queries on time-series data.

## Features

- High-performance time-series database for massive data scale
- Massive ingestion throughput
- Millisecond query response times
- SQL extensions for time-series analytics
- No external dependencies; zero-config deployment
