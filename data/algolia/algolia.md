## Overview

Algolia is a hosted search solution that provides typo-tolerance, relevance ranking, and UI libraries to help developers create search experiences. It is delivered as a managed service accessed via API rather than self-hosted software.

## Features

- Typo-tolerant search
- Relevance ranking and custom ranking
- UI libraries for building search interfaces
- Developer documentation search (offered for free)
- API-based integration

## Pricing

The free "Build" plan includes 1M documents and 10K searches per month. Additional usage is billed under paid plans.
