## Overview

Meilisearch is an open-source search engine that blends full-text and semantic search, designed for fast and relevant search experiences.

## Features

- Blends full-text and semantic search
- Search across global edge locations
- Flat-rate pricing regardless of search volume
- Fast, relevant search with minimal configuration
- Typo tolerance and instant search

## Pricing

Open source. Managed cloud options available via Meilisearch Cloud.
