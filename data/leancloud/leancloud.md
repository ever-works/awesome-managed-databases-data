## Overview

LeanCloud is a mobile backend-as-a-service platform providing data storage, user management, and push notifications for mobile applications, with an API similar to Parse Platform.

## Features

- 1GB data storage (free)
- 256MB instance (free)
- 3K API requests/day (free)
- 10K pushes/day (free)
- Parse Platform-compatible API

## Pricing

Free tier includes 1GB data storage, 256MB instance, 3K API requests/day, and 10K pushes/day. Paid plans for higher limits.
