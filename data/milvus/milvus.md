## Overview

Milvus is an open-source vector database built for AI applications, optimized for similarity search over embeddings at massive scale.

## Features

- Open-source vector database optimized for similarity search
- Scales to billions of vectors with minimal performance loss
- Built for GenAI and machine learning workloads
- Supports hybrid search and metadata filtering
- SDK support for multiple languages
