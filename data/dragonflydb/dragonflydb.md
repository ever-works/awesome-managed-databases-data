## Overview

DragonflyDB is a high-performance, multithreaded, in-memory data store compatible with Redis and Memcached APIs.

## Features

- High-performance, Redis-compatible in-memory data store
- Up to 25x more throughput than legacy solutions
- 80% lower costs than legacy solutions
- Multithreaded architecture
- Drop-in replacement for Redis and Memcached

## Pricing

Open source. Managed cloud options available via Dragonfly Cloud.
