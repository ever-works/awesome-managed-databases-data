## Overview

NocoDB is an open-source no-code database and app builder that turns any database into a smart spreadsheet.

## Features

- Open-source platform for building databases, internal apps, and automated workflows
- No-code database and app builder
- Spreadsheet-like interface
- Available on cloud or self-hosted
- Connects to MySQL, PostgreSQL, SQL Server, SQLite, MariaDB, and more

## Pricing

Open source under the MIT license. Hosted cloud options available via NocoDB Cloud.
