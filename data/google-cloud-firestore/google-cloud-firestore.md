## Overview

Google Cloud Firestore is a fully managed NoSQL document database service provided by Google Cloud Platform. It offers a free tier with 1GB of storage, 50,000 reads, 20,000 writes, and 20,000 deletes per day.

## Features

- Fully managed NoSQL document database
- 1GB storage on free tier
- 50,000 reads per day on free tier
- 20,000 writes per day on free tier
- 20,000 deletes per day on free tier
- Part of Google Cloud Platform

## Pricing

Freemium model. Free tier includes 1GB storage, 50,000 reads, 20,000 writes, and 20,000 deletes per day. Paid tiers available beyond free tier limits.

## Deployment

Cloud (Google Cloud Platform)
