## Overview

Convex is a reactive backend-as-a-service that combines a document database with ACID transactions, serverless functions, and WebSocket-based real-time updates for modern web and mobile applications.

## Features

- Document database with relationships
- Serializable ACID transactions
- Serverless functions
- WebSockets for real-time updates to clients
- Reactive data synchronization

## Pricing

Free for small projects: up to 1M records and 5M monthly function calls. Paid plans for production workloads.
