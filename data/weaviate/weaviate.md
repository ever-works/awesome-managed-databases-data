## Overview

Weaviate is an open-source vector search engine and vector database built for AI and machine learning applications.

## Features

- Open-source vector database designed for AI applications
- Store, search, and retrieve embeddings
- Semantic similarity matching and metadata filtering
- Hybrid search (keyword + vector)
- Modular architecture with AI-native integrations

## Pricing

Open source under the Apache-2.0 license. Managed cloud options available via Weaviate Cloud.
