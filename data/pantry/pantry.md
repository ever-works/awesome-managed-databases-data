## Overview

Pantry is a simple JSON data storage API perfect for personal projects, hackathons, and mobile apps. It lets developers store and retrieve JSON documents via a REST API without operating a database.

## Features

- REST API for JSON document storage
- Simple key/value-style access to JSON blobs
- Suitable for personal projects, hackathons, and mobile backends
- No database management required
